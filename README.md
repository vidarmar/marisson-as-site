# Marisson — Aero & Digital (website)

Static site for GitHub Pages. Same content as maravconsult.com, with the new
Marisson logo (setup A: symbol + MARISSON + AERO & DIGITAL between orange rules).

Files
- index.html          – the page (hero photo embedded)
- favicon.svg         – browser tab icon
- img/logo-symbol.svg – logo symbol used in the header
- img/apps/           – app icons (Jarl, VitalHer)

Publish: create a repo, upload all files keeping the folder structure,
then Settings → Pages → Deploy from branch → main / root.
